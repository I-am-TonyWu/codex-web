# Release retention

Keep the latest three codex-web patch versions locally. Before every deletion batch, present exact paths, versions, and expected reclaimed bytes, and obtain the user's explicit confirmation. Without confirmation, retain additional versions. Never delete the active installation, unknown-version files, Git history, or D-drive migration/backup copies under this policy.

The currently proposed deletion of versions older than 1.6.0 is still awaiting confirmation. Preserve versions 1.6.0 and 1.6.1.
