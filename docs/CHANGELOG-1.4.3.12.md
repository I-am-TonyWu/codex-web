# 1.4.3.12 — 对话显示与任务状态

2026-10-11。本版原为本地构建，现已合入 [1.4.4 预览版](releases/1.4.4.md)，没有单独发行附件。

- 将连续命令及查看图片合并为自然语言操作摘要，命令、输出和过程图片默认折叠，点击后查看。
- 保留叙述和轮次边界；用户图片、已知图片生成结果和最终答复图片正常显示。生成图片在服务端转存时保留用途标记。
- 固定显示任务状态：提交、运行、等待处理、完成、停止、错误和状态待确认。连接异常时不继续显示已确认的旧状态；终态来自后台轮次，单条命令成功不会宣称整个任务结束。
- 等待处理和错误状态提供定位入口；工具失败在操作摘要单独提示，不混同整个任务失败。
- 思考过程默认折叠，文件修改摘要使用自然语言；消息窗口按可见条目计数，长工具组不会挤掉之前的文字。
- 沿用明暗主题和现有布局。未改变发送、停止、审批、账户和会话交接规则，未新增模型请求或轮询。

验证包括类型检查、99 项相关单元回归、真实组件的展开/收起及六种状态切换、375px/1440px 明暗主题截图。界面状态素材用于隔离验证，没有发起真实模型任务；手机外网现场使用未验证。
