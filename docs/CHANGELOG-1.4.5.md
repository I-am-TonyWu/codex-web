# 1.4.5 本地修订

2026-10-11。当前仅本地构建和安装；GitHub 预览版仍为 1.4.4。

- 客户端历史和网页新对话统一显示图片缩略图、文件附件和用户正文。只识别完整的附件说明前缀，隐藏重复的图片地址和机器说明，保留用户正文中的标题和路径。存储的消息不改写。
- 标题加大加粗，减少标题栏垂直留白。标题旁添加三个点，复用侧栏同一菜单、定位和操作；鼠标悬停、键盘聚焦时出现，触屏直接显示。收起侧栏后仍可使用。
- 对话菜单、重命名与归档说明、分叉、复制、图片预览、输入提示和思考强度补齐中文。Git 分支名称和模型标识保留原名。
- 设置新增 A−、A+ 和百分比复位按钮，支持 100%、110%、125%、150%；即时应用并在当前浏览器保存。文字与界面间距一起缩放，空间不足时字号控件换行。修复深色下拉框样式污染整页根字号、边距的问题。
- 保持任务状态和默认折叠控制位于输入框上方；展开的说明使用可读字号。

“分叉”从所选回答所在轮次复制对话历史，创建新对话并删去新副本中较晚的轮次。原对话保留；使用同一工作目录，不创建 Git 分支或独立文件副本，也不回退已修改的文件。运行中的对话需等待当前轮次结束。

后续定制版本只使用 `主版本.次版本.修订号`：本次 1.4.5，下一版 1.4.6。历史四位版本记录保留原号；上游 package.json 的 0.1.91 仅标记源码来源。

验证：附件解析与显示回归、完整页面的图片放大/菜单一致性/键盘与触屏/侧栏收起/字号保存与边界、旧设置及快捷键、类型检查、前端与服务构建、托盘测试。测试夹具不调用真实模型、不分叉或归档实际用户对话。
