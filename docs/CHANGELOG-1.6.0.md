# 1.6.0 — Codex / OpenCode 双服务托盘

- 悬停分两行显示状态；图标外圈左侧代表 Codex，右侧代表 OpenCode。绿为正常，黄为处理中，红为异常，灰为停止或等待桌面启动。
- 双击打开两个本机网页，设置中分别提供打开、开启、关闭和重启服务按钮。
- OpenCode 使用官方共享后台服务命令。监控、关闭 Codex 和退出托盘不会停止 OpenCode。
- 登录设置提供独立的 Codex 网页密码和 OpenCode 服务器密码入口。OpenCode 修改密码会重启共享服务并注销旧登录会话，可能中断任务。
- 站点配置支持一个 Access 应用中的多个精确域名，兼容原单域名配置。窗口显示时重新加载；读取失败明确报错并禁止覆盖配置，成功保存后重新读取验证。
- Access 白名单由共享应用统一管理；服务各自的网页密码仍独立。浏览器登录 Cloudflare 和托盘 API Token 分别管理。
- 新增双服务回归检查，包括认证错误、官方服务调用、Windows 参数转义、双域名保存、实际显示后的字段和失败刷新保护。
