# 对话显示优化

2026-10-11。目标：默认阅读自然语言进展和最终结果，按需查看工具记录；滚动阅读历史时仍能确认当前任务状态。1.4.4.1 将 12px 任务提示和默认折叠的会话控制移到输入框上方；展开时显示操作，长说明限制高度，保持消息区和输入框可用。

沿用现有明暗主题、导航和聊天列宽。连续命令及查看图片合并成自然语言摘要，保留叙述和轮次边界。摘要不显示脚本、绝对路径或输出；点击后可查看每项命令，过程图片在展开后才创建和加载。用户上传图片、已知图片生成结果和最终答复中的图片正常显示。

任务状态栏位于消息滚动区外，覆盖同步、提交、运行、等待处理、完成、停止、出错和未确认状态。完成取自后台轮次状态，单条命令成功不会宣称整个任务完成；中间命令失败仍在过程摘要内提示。终态进入历史消息元数据，刷新后可恢复。

验收：命令和过程图片默认收起；键盘可展开；命令失败后成功仍可查到失败；最终结果保留；长工具组不会吞掉前面的叙述；滚动后状态仍可见；窄屏、明暗主题、展开图片及任务终态正常。

性能：分组和显示窗口是线性遍历，窗口按可见条目计数；默认不创建过程图片和命令输出节点，不新增状态轮询或模型请求。沿用已有任务和会话控制状态。

1.4.5：完整识别客户端/网页附件说明，图片只显示缩略图；普通文件保留附件入口。标题采用 18px/粗体（窄屏 16px），标准字号下标题栏约 44px。标题旁菜单复用侧栏菜单，默认隐藏，悬停/聚焦显现；触屏显示入口。菜单支持 Escape 和外部点击关闭，语言随设置切换。字号 100/110/125/150% 仅在当前浏览器保存；根字号标准 16px。沿用明暗主题和既有任务/控制语义。

字号调整即时反馈，不增加装饰动画；菜单入口沿用轻量透明度过渡，减少动态效果设置得到尊重。对话阅读首屏保持静态。测试截图使用隔离夹具，正常流程测试不发送模型请求。录屏工具缺少 ffmpeg 时仅保存状态帧，并记录完整视频播放未验证，不把静态帧当作视频验收。
