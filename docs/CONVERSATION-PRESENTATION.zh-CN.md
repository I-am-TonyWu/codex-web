# 对话显示优化

2026-10-11。目标：默认阅读自然语言进展和最终结果，按需查看工具记录；滚动阅读历史时仍能确认当前任务状态。

沿用现有明暗主题、导航和聊天列宽。连续命令及查看图片合并成自然语言摘要，保留叙述和轮次边界。摘要不显示脚本、绝对路径或输出；点击后可查看每项命令，过程图片在展开后才创建和加载。用户上传图片、已知图片生成结果和最终答复中的图片正常显示。

任务状态栏位于消息滚动区外，覆盖同步、提交、运行、等待处理、完成、停止、出错和未确认状态。完成取自后台轮次状态，单条命令成功不会宣称整个任务完成；中间命令失败仍在过程摘要内提示。终态进入历史消息元数据，刷新后可恢复。

验收：命令和过程图片默认收起；键盘可展开；命令失败后成功仍可查到失败；最终结果保留；长工具组不会吞掉前面的叙述；滚动后状态仍可见；窄屏、明暗主题、展开图片及任务终态正常。

性能：分组和显示窗口是线性遍历，窗口按可见条目计数；默认不创建过程图片和命令输出节点，不新增状态轮询或模型请求。沿用已有任务和会话控制状态。
