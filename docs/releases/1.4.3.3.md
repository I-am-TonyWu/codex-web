# 1.4.3.3 — Desktop project synchronization / 桌面项目同步

## 中文

修复新版 Codex 桌面项目在网页侧边栏中缺失的问题。旧网页只读取保存的文件夹列表，新版改为读取本地项目 ID、名称、顺序和对话归属，保留空项目，并区分项目根目录与历史任务的执行目录。旧版桌面的文件夹列表继续兼容。

页面可见时约每 5 秒检查项目变化，恢复前台时也刷新；短期缓存与请求合并避免重复查询，暂时断网时保留上次成功的侧边栏。项目改名、排序和移除使用针对项目的修改，保留其他桌面配置；写入发现并发变化时拒绝覆盖。ChatGPT 云聊天项目不属于本地工作接口。

EXE 更新方式：退出旧托盘程序，把新 `CodexWebTray.exe` 替换到原路径后启动。当前用户保存的密码、Cloudflare 加密令牌和自启路径不随此版本重置。旧网页需刷新一次才能加载新代码。

验证：现代/旧版项目数据、任务归属、空项目、同名项目、缓存过期与竞争、刷新、网络失败和响应式界面；375×812、768×1024 明暗主题浏览器验证通过；生产构建、打包 CLI 启动和托盘监控/安全测试通过。Windows 上两个既有测试依赖符号链接权限或 POSIX 0600 文件权限，与本次功能无关；分别由本机环境限制而无法通过。

## English

Fix missing sidebar projects after newer Codex desktop releases moved project storage from workspace paths to local project IDs. The web reads project names, order, explicit task assignments, and empty projects while preserving each historical task's execution cwd. Legacy path-based desktop state remains supported.

Visible pages check metadata roughly every five seconds and refresh on foreground return. In-flight deduplication and a short cache avoid duplicate queries. Temporary network errors keep the last successful sidebar. Project mutations preserve unrelated desktop state and reject detected concurrent writes. ChatGPT cloud chat projects are outside the local work backend.

Upgrade by quitting the tray, replacing the EXE at its existing path, and launching it again. This version preserves the current user's password, encrypted Cloudflare token, and startup path. Reload already-open web pages once to load the new frontend.

Verified modern/legacy metadata, memberships, empty and same-name projects, cache expiry and races, reload persistence, network failures, responsive light/dark UI at 375×812 and 768×1024, production builds, packaged CLI startup, and tray monitor/security checks. Two existing tests need Windows symlink privileges or POSIX file permissions unavailable in this Windows environment.
