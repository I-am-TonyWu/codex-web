# 1.4.3.4 — Chat project assignment / 聊天归入项目

## 中文

上一个 GitHub 公开版本为 **1.4.3.1**。本次公开发行版包含以下累计更新：

- **新增聊天项目菜单（1.4.3.4）**：在网页侧边栏右键聊天，或点击省略号 → **项目**。可以归入本地项目、换项目或移回“无项目（普通聊天）”；支持搜索、当前归属勾选、保存期间禁用重复点击和失败提示。修改桌面共享的归属元数据，不移动文件、不改聊天内容及历史工作目录。网页刷新后保持归属；某些桌面版本缓存侧边栏时，需要刷新或重新打开客户端才能显示外部变更。
- **修复桌面项目同步（1.4.3.3）**：兼容新版项目 ID、名称、顺序、空项目及明确的聊天归属，保留旧版文件夹列表兼容。网页可见时约每 5 秒刷新，回到前台时刷新；请求合并和短期缓存减少重复查询，断网时保留上次侧边栏。项目名称、顺序和移除使用针对性修改并检测并发变化。
- **新增 Mermaid 图形渲染（1.4.3.2）**：对话中的 Mermaid 代码显示为图形，支持明暗主题、查看源码和放大预览；依赖随程序打包，无需外部 CDN。格式错误或流式输出尚未结束时保留源码，避免聊天渲染中断。
- **更新迁移支持**：提供通用导出、恢复和校验脚本及中英文说明，支持新版项目对象的 `rootPaths` 路径迁移，保持项目和对话 ID。完整私人迁移包单独保存，包含最新聊天、技能插件及项目文件；不会上传公开 GitHub。

已移除的源项目自动更新功能保持移除，避免覆盖本项目定制。普通 ChatGPT 网页聊天转发不包含在本版本。所有允许登录的邮箱仍共享同一个本机 Codex 环境。

**升级**：退出旧托盘，替换原路径的 `CodexWebTray.exe`，然后启动；已打开的网页刷新一次。已有网页密码、Windows 当前用户加密保存的 Access Token 和自启位置不因升级重置。新安装需先配置自己的 Cloudflare 目标，发行包不包含账户凭据或私人数据。

**验证**：207 个网页测试通过；两个既有测试因 Windows 符号链接权限 / POSIX 文件权限限制而跳过。生产构建、打包 CLI 启动、19 个托盘监控检查和 32 个公开包装器配置/安全检查通过。浏览器覆盖项目移动及移回、刷新持久化、保存锁定、失败重试、搜索，375×812 / 768×1024 明暗主题；空闲 10.5 秒仅 2 次项目查询。使用隔离目录验证真实 HTTP 写入和迁移脚本，不向模型发送测试消息。发行文件经过凭据和私人配置排除检查。

## English

The previous GitHub release was **1.4.3.1**. This release includes these cumulative changes:

- **Chat project menu (1.4.3.4)**: right-click a sidebar chat or use its ellipsis → **Project**. Assign it to any local project, change projects, or select **No project (ordinary chat)**. Includes search, current-membership checks, save locking, and retryable errors. Only shared desktop membership metadata changes; messages, files, and historical working directories are preserved. Membership persists after web reload. Desktop versions that cache their sidebar may need a refresh/reopen to show external changes.
- **Desktop project synchronization (1.4.3.3)**: reads modern project IDs, names, ordering, empty projects, and explicit memberships, with legacy workspace compatibility. Visible pages poll about every five seconds and refresh on foreground return; shared short-lived caching prevents duplicate reads and temporary errors preserve the previous sidebar. Scoped project writes detect concurrent changes.
- **Mermaid rendering (1.4.3.2)**: renders diagrams in messages, with theme support, source display, and expanded preview. Libraries are bundled locally. Invalid or incomplete streaming diagrams fall back to source instead of breaking the chat.
- **Migration support**: reusable snapshot, restore, and verification tools plus bilingual instructions. Modern project `rootPaths` migrate while project and conversation IDs stay intact. Full private migration snapshots are stored separately and are never published to GitHub.

The upstream updater remains removed to preserve customizations. ChatGPT website forwarding is not included. All authorized emails still share the same host Codex environment.

**Upgrade**: quit the tray, replace the EXE at its existing path, launch it, and reload open web pages. Existing passwords, current-user encrypted Access tokens, and the startup path are preserved. Fresh installations configure their own Cloudflare target; releases contain no account credentials or private data.

**Validation**: 207 web tests passed; two existing Windows symlink/POSIX permission tests were skipped. Production build, packaged CLI startup, 19 monitor checks and 32 public-wrapper configuration/security checks passed. Browser checks cover assignment and removal, reload persistence, saving locks, failure recovery, search, and light/dark layouts at 375×812 and 768×1024; only two metadata reads in 10.5 idle seconds. Isolated HTTP and migration fixtures do not send model requests. Public source and payload privacy checks exclude credentials and personal configuration.
