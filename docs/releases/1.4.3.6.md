# 1.4.3.6 — Stable backup / 稳定版备份

## 中文

相较上一个公开版 1.4.3.4，累计包含 1.4.3.5 和 1.4.3.6 的修复：

- RPC 错误保留 JSON 原因，避免 Cloudflare 将应用拒绝替换成整页 HTML 502。
- 历史查看只读取，发送才取得写入权；网页任务结束后优雅释放自己的闲置会话，等待实际关闭确认。
- 增加“重试原对话”，保留原 ID、历史、项目归属及未发送草稿；明确选择独立接续时才创建分支。
- 修复旧只读状态缓存和分支路由草稿恢复问题；不自动重复发送不确定是否送达的消息。
- 收录 Windows MXC 沙箱修复说明。沙箱修复依赖已验证的主机 Codex 配置，并非 EXE 自动修改所有主机；网页仍采用 workspace-write/on-request。

验证：78 项相关网页/生命周期测试、7 项桥接测试、两个隔离原生 app-server 的同 ID 交接及本地模拟任务释放、手机/平板浅色/深色重连和分支流程通过。没有真实模型请求。公开包装器监控/安全测试、生产构建和 EXE 打包通过。Docker 矩阵、Windows 重启和真实手机现场复测未执行。

下载 `CodexWebTray.exe` 并核对 `SHA256SUMS.txt`。正常退出旧托盘，在固定安装路径替换 EXE，再启动并刷新网页。保留 `%LOCALAPPDATA%\CodexWebTray` 和当前用户注册表即可保留密码、Token、自启及站点设置。旧私人定制版本转为通用发行包时，需要在“Cloudflare 站点”补齐自己的资源 ID；不要把 Token 上传 GitHub。

1.4.3.6 为稳定回退版本；所有历史公开发行版继续保留在 [Releases](https://github.com/I-am-TonyWu/codex-web/releases)。每个版本绑定独立标签和附件，不覆盖旧发行文件。

## English

Cumulative changes since public 1.4.3.4 include JSON RPC failure handling through gateways, reader-only history browsing, graceful idle writer release, same-ID retry with preserved drafts, explicit independent continuation, and removal of stale read-only resume caching.

Windows MXC troubleshooting is documented separately: it relies on a validated host Codex configuration, not an unconditional EXE-side change. Web permissions remain workspace-write/on-request.

Validation includes 78 focused tests, 7 bridge tests, isolated real app-server handoff with a localhost-only provider fixture, phone/tablet light/dark browser flows, public-wrapper checks and production builds. No real model requests. Docker matrix, Windows reboot and physical phone acceptance were not run.

Quit the old tray, replace the EXE at its fixed path, launch and refresh the browser. Preserve the user data and registry to keep credentials and startup settings. This release is a stable fallback. Each published version retains its own tag and assets in the complete release history.
