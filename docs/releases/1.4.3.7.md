# 1.4.3.7 — 会话控制预览版 / Conversation control preview

稳定版仍为 [1.4.3.6](https://github.com/I-am-TonyWu/codex-web/releases/tag/v1.4.3.6)。[全部历史版本](https://github.com/I-am-TonyWu/codex-web/releases)。此版不替换稳定版下载入口，支持在同一安装路径回退。

## 相较于 1.4.3.6

- 每个已认证的网页标签页有独立控制身份；多个网页可以看同一条历史，只有当前控制端能发送、停止、引导、审批、改名、归档、回滚、修改项目归属或操作该对话的终端。
- 新增会话控制栏：**取得控制权 / 接管此对话、退出控制、刷新状态**。浏览历史、刷新页面或输入草稿不会抢占。最新一次成功确认的明确接管取得控制权；迟到的旧发送、停止和审批请求由服务端拒绝。
- 网页之间接管时当前任务继续，保持原对话 ID、历史和项目归属。**停止任务并接管**需要确认，等待实际任务完成后才交接；停止不撤销已完成的文件修改。超时不伪装成空闲。
- 心跳 5 秒，30 秒失联后控制权失效；手机后台不再续租。断线、退出或服务重启不会重复发送消息，也不会因网页断开而取消正在执行的后台任务。
- 发送前写入请求编号记录；同一请求不会重复创建轮次。结果无法确认时保留待确认标记，可在**交接说明 → 核对发送结果**中查询；人工核对历史后才能清除不确定标记。
- 草稿按标签页独立保存，刷新仍保留，发送失败会恢复草稿。标签页关闭后的草稿恢复不作保证；重要内容请先复制。旧版共享草稿作为迁移来源保留，回退不删除它。
- 队列按对话合并，防止旧页面整体覆盖他人的队列；交接、失联或服务重启后旧队列暂停保留。编辑并明确重新排队，或手动发送，才重新授权。已进入后台执行的轮次不因此停止。
- 保留 1.4.3.6 的闲置写入权释放、原对话重试、网关 JSON 错误处理、主机 MXC 沙箱配置和 Token 持久化功能。

## 能力边界

**桌面远程释放暂不可用**：当前 Windows Codex 客户端没有向托盘提供经验证、可独立打包的指定会话控制接口。网页界面会说明原因，并禁用“释放桌面会话”。检测到外部写入锁时保留只读和“重试原对话”；也保留显式创建网页分支的原有选项。不会结束整个桌面进程、删除锁文件或冒充释放成功。

因此本版实现网页 A/B 的最新明确接管优先，尚未实现 Windows 原生客户端和网页之间完全对称的自动交接。定时任务、项目级配置及不同对话之间共享文件的冲突不由浏览器控制权隔离。所有允许邮箱继续共享同一本机环境。

## 升级与切换

等网页任务结束，退出托盘，校验下载的 `CodexWebTray.exe`，在原固定路径替换并启动，然后刷新所有网页。密码、Cloudflare Token、站点配置和开机自启设置保留；控制凭证在服务重启后重新取得。主机的 `[windows] sandbox = "mxc"` 不随 EXE 回退而撤销，具体见[沙箱说明](../WINDOWS-SANDBOX.md)。

本地发送记录位于当前 `CODEX_HOME/webui-send-receipts.jsonl`，只记录编号、身份摘要、参数摘要、状态和 turn ID，不保存消息原文或控制密钥。保留最近 30 天记录，内存上限 10,000 个请求；达到上限会停止接受新发送并提示维护，避免静默失去去重保护。服务端每轮运行最多注册 512 个终端、4096 条控制状态，达到上限会提示重启网页服务；请先等待活动任务结束。

## 验证

TypeScript 检查、生产网页和 CLI 构建；97 项单元/回归测试及 7 项写入锁恢复测试。隔离的真实 Codex app-server + 本地模拟提供商验证运行中接管、迟到请求拒绝、停止等待、队列暂停和同请求只创建一轮，无真实模型调用。375×812 与 768×1024、明暗主题、同一浏览器两个标签页验证草稿隔离和控制栏；原对话恢复流程回归。托盘监控与配置测试 51 项。

Docker 不可用，Docker 平台矩阵未运行。手机实机及 Windows 重启后完整远程链路没有在本轮代替用户验证；安装后服务、Token 和配置保留单独核对。

## English

This prerelease adds one controller per authenticated browser tab while allowing multiple readers of the original thread. Explicit takeover fences stale sends, interrupts, approvals and thread mutations. A running web task continues during transfer. Stop-and-takeover waits for executor completion and does not undo file changes.

Five-second heartbeats expire after 30 seconds without cancelling running tasks. Per-tab drafts survive refresh, with no guarantee after closing a tab. Failed sends restore drafts. A durable request journal prevents accepted requests from creating duplicate turns; uncertain delivery requires checking history before clearing the marker. Queues retain their messages but pause after ownership changes, disconnects or service restarts until explicitly edited/requeued or sent manually.

**Remote desktop release is unavailable in this preview.** No portable, verified native desktop adapter has been established. The disabled action explains this limitation; desktop-owned history stays read-only until normal release and retry. The program never kills the desktop process or deletes writer locks. This release does not claim symmetrical desktop/browser control, account isolation, or project-file isolation.

Quit the tray after tasks finish, verify the checksum, replace the EXE at the same path and reload browsers. User passwords, Cloudflare credentials, site configuration and autostart settings remain local. Stable 1.4.3.6 and all earlier published releases remain available separately. See the Chinese validation section for exact coverage and limits.
