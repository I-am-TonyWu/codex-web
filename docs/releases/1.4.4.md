# 1.4.4 Preview — 对话显示与主机连接 / Conversation display and host connection

2026-10-11。此版标记为 **Pre-release**。稳定版仍为 [1.4.3.6](https://github.com/I-am-TonyWu/codex-web/releases/tag/v1.4.3.6)，[全部历史版本](https://github.com/I-am-TonyWu/codex-web/releases)继续保留。

## 相较于公开预览版 1.4.3.9

- **对话阅读更简洁**：连续命令与查看图片合并成自然语言操作摘要。原始命令、输出、过程图片和思考过程默认折叠，点击后查看。用户上传图片、已知原生图片生成结果和最终答复图片正常显示。长工具组按摘要计数，保留前面的文字进展。
- **任务状态始终可见**：状态栏位于消息滚动区外，区分提交、运行、等待处理、完成、停止、错误和连接待确认。任务终态来自后台轮次，单条命令成功不会宣称任务结束。工具失败在摘要中单独提示；等待处理和错误提供定位入口。
- **账户由 Windows Codex 持有**：网页只连接主机已有登录，移除账户管理、网页登录和 Telegram。旧账户/Telegram 接口返回 410 JSON，账户写入 RPC 拒绝；网页后台只使用内存中的主机访问令牌，不进行 OAuth、刷新令牌请求或写入主机登录文件。主机账户操作在 Windows 客户端完成。
- **设置与错误处理**：额度位于设置顶部，Ctrl+Enter 的提示与实际发送行为一致；网关 HTML 错误转换为可读的 JSON 错误。提供方切换保留配置，并在活动任务、审批或待确认状态下阻止切换。
- 托盘、网页和安装包版本统一为 **1.4.4**，包含此前本地 1.4.3.10–1.4.3.12 的更新；这些中间构建不单独公开发行。上游包版本 0.1.91 用于来源归属。

## 下载与升级

下载 `CodexWebTray.exe` 和 `SHA256SUMS.txt`，核对校验值。等任务结束后退出旧托盘，在原路径替换 EXE，再启动并刷新网页。保留用户配置、加密凭据与 `.codex` 数据。安装包不包含账户凭据、私人聊天或站点配置。

回退至 1.4.3.6 或更早版本之前，先保存并移除待发送队列；旧版本会自动继续旧队列。完整步骤见[版本切换说明](../RELEASES.md)。

## 验证范围

类型检查、前端/CLI 构建、116 项相关对话、会话控制及主机连接回归以及 51 项托盘监控/安全配置测试通过。对话显示已用真实组件覆盖 65 个命令、8 张过程图片、六种状态、键盘展开/收起及 24 个手机/桌面明暗主题截图；原历史对话安装后核验了折叠图片和固定完成状态。

状态切换使用隔离素材，没有发送真实模型消息。手机外网连续使用、Windows 重启及真实桌面任务发送/回复未现场验收；桌面协同使用客户端内部接口，后续兼容性仍需验证。

## English

This prerelease combines local builds 1.4.3.10–1.4.3.12 with the previous public 1.4.3.9 preview. Stable Latest remains 1.4.3.6.

Tool operations now use natural-language summaries. Commands, output, process images and reasoning stay collapsed until opened; uploaded images and final results remain visible. Task status stays outside the message scroll area and distinguishes running, completed, stopped, failed, waiting for input and uncertain connection state. Completion follows the backend turn status rather than a successful tool command.

Codex authentication remains owned by the Windows host. The browser no longer manages Codex accounts or Telegram. The web backend uses only an in-memory host access token, without OAuth, refresh-token requests or writes to the host login file. Quota appears at the top of settings, Ctrl+Enter behavior matches its label, and gateway errors are readable JSON.

Download the EXE and checksum, quit the tray after tasks finish, replace it at the existing path, launch and reload browsers. Preserve local configuration and credentials. Copy and remove pending queues before downgrading to 1.4.3.6 or earlier.

Validation covers type checking, builds, 116 related regressions, 51 tray tests and 24 responsive/theme status screenshots. Historical conversation collapse and persistent completion status were checked in the installed app. State transitions used isolated fixtures; no real model requests were sent. Physical mobile continuity, Windows reboot and actual desktop send/reply remain unverified.
